# homebrew-tap

dunzkoi의 Homebrew tap.

## 사용

```bash
brew tap dunzkoi/tap
brew install cw
```

또는 한 줄:
```bash
brew install dunzkoi/tap/cw
brew install --cask dunzkoi/tap/loupecast
```

## Formulae

- [cw](https://github.com/dunzkoi/cw) — Claude Worktree (git worktree + claude -w 통합 CLI)

## Casks

- [Loupecast](https://github.com/dunzkoi/loupecast) — 클릭 자동 확대와 컷 편집을 지원하는 화면 녹화 앱 (Apple Silicon, macOS Sequoia 이상)
